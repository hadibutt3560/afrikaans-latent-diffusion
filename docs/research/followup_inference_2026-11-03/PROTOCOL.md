# Follow-up inference checks: sampling audit, fitted prior and fresh reconstruction

This inference-only protocol, which remained a draft without explicit approval (job 81249 was submitted on 3 November 2026 with the draft unchanged, and `analyze.py` was written before any result was read), set three checks on autoencoder D (job 77176) with no training, tuning or test-split reads. F1 sampled 100 latents per checkpoint (seeds 70000 + i) from the six D denoisers (small and published, seeds 42–44) with the self-conditioning normalisation flag off and on, and called the effect material only if the pooled paired difference in mGPT NLL per token lay outside ±0.10 nats with at least 5 of 6 runs agreeing in sign (2,000 bootstrap replicates, seed 20261106). F2 decoded three banks of 1,000 latents from a Ledoit–Wolf Gaussian fitted to D's training latents (seeds 40000, 41000 and 42000 + i), and F3 measured reconstruction by B0, A and D on the 681 `extra_monitor` passages, with paired document bootstrap intervals (2,000 replicates, seed 20261107).

The protocol also fixed the input hashes, the readouts and fixed wording for each check, the in-domain disclosure for D, the order and 20-hour budget of the job and the permitted use in the paper. The full protocol as fixed before the run is at the repository tag `as-run`: https://github.com/hadibutt3560/afrikaans-latent-diffusion/blob/as-run/docs/research/followup_inference_2026-11-03/PROTOCOL.md.
