# AR baseline on the test split

This inference-only check, fixed on 5 November 2026 before any sample was generated, scored the AR baseline on the test split so that the RQ3 rule (diffusion mGPT perplexity at most 1.20 × the AR baseline's) could be applied to the original B0 diffusion (5 runs per size), the retrained D diffusion (3 runs per size) and human test text on one split. The AR checkpoint (update 60,000, hash `ed12edbd…1d076`) drew 1,000 samples with nucleus p = 0.95, temperature 1, up to 127 new tokens, FP32 and seeds 120000 + i for i = 0…999; the scorer had to reproduce four stored anchors to within a relative 1e-4. A system passes if the point ratio is at most 1.20, clearly passes if the upper 95% limit is also at most 1.20, clearly fails if the lower limit is above 1.20, and is otherwise inconclusive.

The protocol also fixed the comparison banks, the further readouts (standardised perplexity, length, distinct-2 and copying), the log-scale interval with a 2,000-resample AR bootstrap (seed 20261105), the required qualifying wording and the output files. The full protocol as fixed before the run is at the repository tag `as-run`: https://github.com/hadibutt3560/afrikaans-latent-diffusion/blob/as-run/docs/research/ar_test_2026-11-05/PROTOCOL.md.
