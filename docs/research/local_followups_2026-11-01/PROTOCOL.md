# Local follow-ups to the 1 November review

These descriptive, exploratory follow-ups added counts or repeated existing measurements on data already used in the study; none tested a new hypothesis or changed a reported result. They used the original B0 autoencoder (job 56531) and the mGPT scorer in FP32 on one RTX 3060, did not read the test split or the reserve documents (positions 64–127 of the seed-91427 validation shuffle), and evaluated only one new text set, `extra_monitor.jsonl` (681 passages). The shuffle-sensitivity task first had to reproduce the stored outputs exactly and then used seeds 20261111–20261115; the four extra random latent banks of 1,000 latents used seeds 31000+i, 32000+i, 41000+i and 42000+i, with length-standardised perplexity weights 0.140, 0.223, 0.349 and 0.288 and at least 20 rows per band.

The protocol also defined the CPU tasks (numeral accuracy, training–validation 12-gram overlap, token lengths, Figure 1 values, partial copies and scorer agreement) and the output layout under `outputs/local-followups/`. The full protocol as fixed before the run is at the repository tag `as-run`: https://github.com/hadibutt3560/afrikaans-latent-diffusion/blob/as-run/docs/research/local_followups_2026-11-01/PROTOCOL.md.
