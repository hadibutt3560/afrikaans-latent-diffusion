# Swahili checks: reconstruction, random latents, language and copying

Fixed on 1 November 2026 before any model was run, these exploratory, inference-only checks applied to the Swahili run (job 66417, two seeds per size) the tests that had changed how the Afrikaans results were read, all on the validation side. S1 reconstructed a panel of 200 validation passages (seed 20261102) with correct and shuffled latents (derangement seed 20261103) and gave source-file bootstrap intervals (2,000 replicates, seed 20261104); S2 decoded 1,000 random latents (seeds 40000 + i) and used fixed wording around a 1.20× ratio to the mean diffusion validation perplexity; S3 measured the GlotLID `swh_Latn` share; and S4 measured length and copying from the training split. Integrity gates had to pass first, including scorer reproduction within a relative 1e-4 and autoencoder cross-entropy within 2% of the stored validation value (corrected by a dated note to `ae-gate.json`, CE 0.4957).

The protocol also fixed the inputs, the readouts, the output files, the wording and limits of the single paper paragraph and a budget of about 1.5 GPU hours. The full protocol as fixed before the run is at the repository tag `as-run`: https://github.com/hadibutt3560/afrikaans-latent-diffusion/blob/as-run/docs/research/swahili_check_2026-11-01/PROTOCOL.md.
