# Stage 3: bounded decoder improvement investigation

This stage tested one decoding change: whether setting no_repeat_ngram_size from 3 to 0 improved reconstruction by the final autoencoder (job 56531, step 30500) on the 81 diagnostic validation passages from 64 documents, with all other decoding settings unchanged (FP32, beam 4, max length 128, batch 1) and the baseline outputs first reproduced exactly. The primary endpoint was mean sentence chrF with a paired document bootstrap of 10,000 replicates (seed 91428); the change would advance only if chrF improved by at least 2 points with a wholly positive 95% interval, numeric recall fell by no more than 2 percentage points and inspection found no content regression, and only then would the fixed 103-passage reserve be used for confirmation.

The protocol also set resource stop rules (2 GPU-hours, 10 GiB) and recorded the decision not to repeat terminal latent projection without new evidence of a norm mismatch. The full protocol as fixed before the run is at the repository tag `as-run`: https://github.com/hadibutt3560/afrikaans-latent-diffusion/blob/as-run/docs/research/stage3_improvement_2026-10-22/PROTOCOL.md.
